# Flow_Support_Chat

Tài liệu nghiệp vụ cho hệ thống Browser Extension Chat Support, AI First Response, định tuyến và phân công nhân sự hỗ trợ khách hàng, tích hợp Bitrix24.

## Tài liệu

- [Đặc tả nghiệp vụ tổng thể](docs/01-business-workflow-specification.md): phạm vi, vai trò, luồng Mermaid, mô tả từng bước, quy tắc phân nhóm và phân công M-Tech Care, vòng đời Conversation/Ticket, xử lý ngoại lệ, bảo mật, cấu hình, tiêu chí nghiệm thu và các quyết định còn mở.

## Trạng thái

Tài liệu là baseline nghiệp vụ để trao đổi giữa nghiệp vụ và Dev. Các mục “Quyết định còn mở” phải được xác nhận trước khi chốt thiết kế kỹ thuật. Tài liệu này chưa quy định schema database, API cụ thể hoặc loại đối tượng Bitrix24.
